# Travel Guide Website

A multi-page travel guide website focused on exploring India through
destinations, regional travel, cuisine, and practical travel tips.

## About the Project

This project was created to provide users with a simple and organized
way to explore different aspects of traveling in India.

The website contains information about destinations, Indian cuisine,
regional travel, and useful travel tips.

## Pages

- Home
- About
- Cuisine
- South India
- North India
- Travel Tips
- Contact

## Technologies Used

- HTML5
- CSS3

## Features

- Multi-page website
- Navigation between pages
- Information about Indian destinations
- Regional travel sections
- Indian cuisine section
- Travel tips
- Contact page
